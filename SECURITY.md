# Security Policy

## Reporting a Vulnerability

Please do not open a public issue for a suspected security vulnerability or accidental credential exposure.

Use GitHub's **Report a vulnerability** flow in the repository Security tab to create a private security advisory. Include:

- The affected CodexMeter version and macOS version.
- Reproduction steps and expected impact.
- Relevant logs or screenshots with credentials and personal data removed.
- Any suggested mitigation, if available.

The maintainers will review the report, confirm its scope, and coordinate a fix and disclosure when appropriate.
